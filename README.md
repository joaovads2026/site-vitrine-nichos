# FORMA. — Site vitrine mobile-first

Projeto estático, sem Supabase, sem banco de dados e sem dependências de build.

## Inclui
- Vitrine principal
- Barbearia
- Salão de beleza
- Corretor de imóveis
- Oficina automotiva
- Autopeças
- Clínica odontológica
- Mobile-first
- Efeitos 3D em CSS
- Formulário demonstrativo

## Publicação
Pode ser publicado diretamente no Cloudflare Pages sem comando de build. Diretório raiz: `/`.
